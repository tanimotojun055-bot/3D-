3Dハッシュの拡散実験

内部の1マスを変えると、何回の混合で6面に差が広がるか

(私設)重力時空研究所・谷本
2026年11月24日

8×8×8の立体格子で、外周を固定し、内部の1マスだけを変えた。3D混合を4回から5回に増やすと、6面・24領域に現れるビット反転率が、代表例で 39.23%から50.16% に上がった。別に行った1ビット変更の256例でも、5回の反転率は 48.96～50.61% に収まった。この結果から、今回の格子で拡散を調べる際は、5回混合を比較の基準とする。

1．何を変え、何を測ったか

表面の値が同じでも、立体の内部には異なる値を置ける。そこで、外周をまったく変えずに内部の1マスだけを変更し、その違いが6面のどこまで届くかを調べた。

1セルは64ビットとし、座標 \(x,y,z\) をそれぞれ0～7とする。最初の立体を次の式で作る。

\[
P_0(x,y,z)=8+2x+4y+6z
\]

同じ立体をもう一つ用意し、座標 \((3,3,3)\) だけを変更する。

\[
P_0(3,3,3)=44,\qquad P'_0(3,3,3)=68
\]

これは1セルの変更であり、44と68を二進数で比較すると3ビットの反転に当たる。二つの立体に同じ計算を施し、各段階で同じ位置にある出力ビットを比較した。

2．24領域と立体全体を、最終32バイトにまとめる一般式

混合を \(r\) 回終えた立体を \(P_r\) とする。今回の実験で使った比較用の最終集約式は、次のとおりである。

\[
\boxed{
D_{32}^{(r)}
=
\operatorname{SHA256}\!\left(
\operatorname{SHA512}\!\left(
B_{24}(P_r)\,\Vert\,V(P_r)
\right)\right)
}
\]

\(B_{24}(P_r)\) は、6面を各4領域に分けた24領域の投影データ。

\(V(P_r)\) は、同じ時点の立体全体のセルを一本に並べたデータ。

\(\Vert\) は、左のバイト列の直後に右のバイト列をつなぐ操作。

\(D_{32}^{(r)}\) は、最終的に台帳のハッシュ欄に記録する32バイト。


今回の格子では、データ量は次のように変わる。

\[
\underbrace{3{,}072}_{24領域}
+
\underbrace{4{,}096}_{立体全体}
=
7{,}168\ \text{バイト}
\]

\[
7{,}168\ \text{バイト}
\xrightarrow{\ \mathrm{SHA512}\ }
64\ \text{バイト}
\xrightarrow{\ \mathrm{SHA256}\ }
\boxed{32\ \text{バイト}}
\]

各セルの64ビット値は上位バイトから書き出す。立体全体を一本にするときは、\(z\) を最も速く進め、次いで \(y\)、最後に \(x\) を進める。SHA-512が出した64バイトは、そのままSHA-256へ渡す。

3．3D混合を繰り返す一般式

第 \(t\) 回の混合操作を \(M_t\) とすると、格子全体の更新は次の式になる。

\[
\boxed{P_{t+1}=M_t(P_t)},\qquad 0\leq t<r
\]

0回なら初期格子 \(P_0\) をそのまま投影する。5回なら、

\[
P_5=M_4\!\left(M_3\!\left(M_2\!\left(M_1\!\left(M_0(P_0)\right)\right)\right)\right)
\]

となる。

1回で、ある1セルがどう変わるか。 現在の値を \(p=P_t(x,y,z)\) とし、X・Y・Zの各方向に格子をずらして読み取った値を、それぞれ

\[
\begin{aligned}
X&=P_t(x-d_x,y,z),\\
Y&=P_t(x,y-d_y,z),\\
Z&=P_t(x,y,z-d_z)
\end{aligned}
\]

と置く。座標が端を越えたら反対側に戻る。試作の更新式は次のとおりである。

\[
\begin{aligned}
C   &= (X\land Y)\oplus(\neg X\land Z),\\
J   &= (X\land Y)\oplus(X\land Z)\oplus(Y\land Z),\\
T_1 &= L_a(X)\boxplus C\boxplus K_t,\\
T_2 &= R_b(Y)\boxplus J
\end{aligned}
\]

\[
\boxed{
P_{t+1}(x,y,z)
=
T_1\oplus T_2\oplus L_d\!\left(L_c(Z)\oplus p\right)
}
\]

\(L_a\) は64ビット語を左へ \(a\) ビット、\(R_b\) は右へ \(b\) ビット循環回転する操作である。\(\boxplus\) は \(2^{64}\) を法とする加算、\(\oplus,\land,\neg\) はそれぞれビット単位のXOR、AND、NOTを表す。

各回の係数。 \(s(u)=1+(u\bmod 63)\) と置くと、4種類の回転量と定数は、

\[
\begin{aligned}
a&=s(7t),            & b&=s(13t+17),\\
c&=s(29t+31),        & d&=s(43t+11),\\
K_t&=\operatorname{SplitMix64}(t)
\end{aligned}
\]

となる。軸番号 \(j=0,1,2\) をそれぞれ \(x,y,z\) に対応させ、格子の辺長を \(n\)（今回は8）とする。各軸のシフト量は、

\[
(u_0,u_1,u_2)=(2t+1,\ 4t+3,\ 6t+5)
\]

\[
d_j=(-1)^{\lfloor t/2^j\rfloor\bmod 2}
\left[1+\bigl(u_j\bmod(n-1)\bigr)\right]
\]

で与える。ここで \((d_x,d_y,d_z)=(d_0,d_1,d_2)\) である。

4．6面・24領域を一本につなぐ一般式

まず、立体の全層を、各面の向きに沿って深さ順に折り込む。面 \(f\) から得られる二次元の投影行列を \(\Pi_f(P_r)\) とする。面の順序は

\[
(f_0,f_1,f_2,f_3,f_4,f_5)=(+X,-X,+Y,-Y,+Z,-Z)
\]

である。

各面を 左上・右上・左下・右下 の順に4分割する。第 \(q\) 領域を取り出す操作を \(Q_q\)、その行列を行順に読んでバイト列にする操作を \(\mathcal E\) とすると、

\[
B_{f,q}(P_r)=\mathcal E\!\left(Q_q\!\left(\Pi_f(P_r)\right)\right)
\]

となる。まず1面の4領域を一本につなぐ。

\[
C_f=B_{f,0}\Vert B_{f,1}\Vert B_{f,2}\Vert B_{f,3}
\]

次に6面を順につなぐ。

\[
\boxed{
B_{24}(P_r)=C_{+X}\Vert C_{-X}\Vert C_{+Y}\Vert C_{-Y}\Vert C_{+Z}\Vert C_{-Z}
}
\]

これが第2節の最終集約式に入る \(B_{24}(P_r)\) である。8×8の面を4分割すると、1領域は4×4セルになる。したがって、

\[
\begin{aligned}
1領域 &=4\times4\times8=128\ \text{バイト},\\
24領域 &=24\times128=3{,}072\ \text{バイト}\\
       &=24{,}576\ \text{ビット}
\end{aligned}
\]

となる。

5．行列の掛け算で表せる部分

格子を軸方向にずらす操作は、行列の積でも表せる。\(h\) マスずらす巡回置換行列 \(S_h\) を、

\[
(S_h)_{ij}=
\begin{cases}
1 & j\equiv i-h\pmod n,\\
0 & \text{それ以外}
\end{cases}
\]

とする。例えば \(y,z\) を固定し、X方向に並ぶセルを列ベクトルにすれば、

\[
\boxed{
X_{i,y,z}=\sum_{j=0}^{n-1}(S_{d_x})_{ij}\,P_t(j,y,z)
}
\]

となる。置換行列の各行には1が一つだけあるため、各セルは指定された位置へ移る。その後に、第3節のビット演算・加算・循環回転を行う。

研究上の照合用に、先に検討した9素数・3×3秘密行列の回転式も記す。秘密行列を \(A\)、直交回転行列を \(R(\theta)\) とすれば、

\[
\boxed{K(\theta)=R(\theta)\,A\,R(\theta)^{\mathsf T}}
\]

成分で書くと、

\[
K_{ij}(\theta)=
\sum_{k=1}^{3}\sum_{\ell=1}^{3}
R_{ik}(\theta)\,A_{k\ell}\,R_{j\ell}(\theta)
\]

である。この式は公開鍵側で検討している回転案に属する。以下の拡散率は、第3節の3D混合と第4節の投影データから測った。

6．代表例の全測定値

内部の1セルを44から68に変え、各回で二つの中間出力を比較した。反転率の分母は常に24,576ビットである。

混合回数	中間出力の反転数	中間反転率	最終256ビットの反転数

0回	34	0.14%	130
1回	276	1.12%	122
2回	1,271	5.17%	131
3回	3,818	15.54%	135
4回	9,641	39.23%	112
5回	12,328	50.16%	123
6回	12,418	50.53%	134


混合0回では24領域のうち6領域に差が現れた。6回では24領域すべてに差が現れた。

最終32バイトでは、混合0回でも256ビット中130ビットが変わった。最終値には比較用のSHA処理の効果も入るため、3D混合を重ねた効果は、集約前の中間反転率で比較すると明瞭に表れる。

7．入力の1ビットだけを変えた追加256例

代表例とは別に、1ビットだけの変更を試した。\(x,y,z\) の各座標を \({1,3,5,6}\) から選び、内部の64か所を用意した。各位置で、下位から0番、15番、31番、63番のビットを一つずつ反転した。これで \(64\times4=256\) 例となる。

混合回数	中間反転率の中央値	最小～最大

4回	37.20%	34.97～39.20%
5回	49.80%	48.96～50.61%
6回	50.06%	49.24～50.95%


4回では全256例が40%未満だった。5回では全例が約49～51%に入った。ここでいう約50%は、入力の1ビットを変えたとき、対応する二つの中間出力を比較すると、約半数のビットの値が異なったという測定結果である。

8．所要時間と結論

今回のPython・NumPy実行環境で、用意済みの格子1個から最終32バイトを得るまでを各101回測定した。中央値は、混合0回で 0.573ミリ秒、6回で 0.944ミリ秒だった。約1.65倍という値は、この環境でハッシュを順方向に計算した際の所要時間比である。

今回の条件では、4回から5回の間で、入力変更の影響が中間出力の約半分に広がった。 代表例と追加256例の両方でこの傾向が見られたため、次の拡散実験では5回を比較の基準とする。

次に確かめたいのは、初期格子や格子サイズを替えても同じ傾向が続くか、出力の特定位置に変化しにくいビットが残るかである。独自の最終混合式、原像耐性、衝突耐性、耐量子性、解読時間は今回の実験では未評価である。
